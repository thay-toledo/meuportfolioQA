# Projeto QA - Sauce Demo

Este projeto tem como objetivo demonstrar a criação e execução de testes manuais na aplicação Sauce Demo.

## Objetivo

Validar funcionalidades principais do sistema, como login, listagem de produtos, carrinho e checkout.

## Aplicação utilizada

Sauce Demo  
https://www.saucedemo.com/

## Tipo de teste

- Teste funcional
- Teste positivo
- Teste negativo
- Teste de validação de campos
- Teste de fluxo de compra

## Ferramentas utilizadas

- GitHub
- Markdown
- Navegador Chrome
- Prints como evidência

## Funcionalidades que serão testadas

- Login
- Logout
- Produtos
- Carrinho
- Checkout
- Validação de campos obrigatórios
