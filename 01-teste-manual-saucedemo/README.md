# Projeto QA - Sauce Demo

Este projeto tem como objetivo demonstrar a criação, documentação e execução de testes manuais na aplicação Sauce Demo, com foco em qualidade de software, análise de cenários e validação de regras de negócio.

## Sobre qualidade de software

Qualidade de software vai além de apenas encontrar erros. Ela envolve garantir que o sistema atenda às necessidades do usuário, funcione conforme o esperado e entregue uma boa experiência durante o uso.

Testar vai muito além de executar cenários prontos. Um bom profissional de QA precisa analisar o comportamento do sistema, pensar em diferentes possibilidades, validar regras de negócio e identificar riscos que possam impactar o usuário final.

## Objetivo do projeto

Validar as principais funcionalidades da aplicação Sauce Demo, simulando cenários reais de uso e documentando os resultados obtidos durante os testes.
